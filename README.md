# Quick Particle — versão 2

Esta versão foi ajustada com base na gravação enviada: campo circular azul, fundo claro, centro translúcido, borda granular e rotação orbital contínua. O toque perturba localmente a esfera.

## Publicar
Envie `index.html`, `manifest.webmanifest` e `sw.js` para a raiz de um repositório GitHub. Ative GitHub Pages em Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Abra o HTTPS no navegador móvel e use Adicionar à tela inicial.

Nota: é uma recriação visual por observação da gravação, não o código ou uma reprodução exata do algoritmo proprietário da Apple.
